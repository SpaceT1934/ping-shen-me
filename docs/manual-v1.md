# V1.1 业务规则（2026-10-17）

## 项目和目标

一个项目对应一棵树，可并行设置多个目标，每个目标对应一颗苹果；其中一个为主要目标。新增目标保留其他进行中的目标，可随时切换主要目标。主要目标达成时，如还有进行中的目标，会自动选择下一个。项目可以编辑名称、结束、归档或恢复；归档不清除历史行动和报告。新增同名项目会提示修改名称。

目标支持数量、百分比和手动确认。数量目标使用整数；百分比目标固定上限 100；手动目标只有未完成和已完成。目标进度可在详情明确更新，也可在确认行动时选择具体目标并填写实际贡献数量；贡献默认 0。AI 只建议关联目标，不推算或写入进度；用户填写正数才视为确认贡献。剪完视频可关联“发布视频”目标，但不能据此自动增加发布数量。任务完成和普通行动不自动推算业务目标进度。

已完成目标不可修改进度；新增目标不会替换旧目标。每个目标最多生成一个成果。

## 记录和任务

手动输入可按句号、分号和换行拆成确认卡片，用户自己选择分类与项目，这不是 AI 语义拆分。Action、Idea 可未归类，Task 必须属于项目；Goal 草稿保存为可未归类的目标建议记录，不会创建或替换正式目标。正式 Goal 必须通过项目详情明确创建。

记录保存实际发生日期，已发生的行动或灵感不允许未来日期。任务可填写未来计划日期。任务完成在同一事务中更新任务、创建行动和成长事件；撤销完成会撤销对应行动；重复完成或网络重试不增加第二条行动。任务生成的行动通过任务编辑或撤销来管理。

手动行动和灵感可编辑、重新分类、重新关联方向或删除。删除为软删除。修改分类、项目或删除时会撤回未完成目标的贡献；只修改文案保留原关联和贡献。已达成果保持达成时快照，不因后续纠错静默撤销。

一批确认卡片通过 `/record-batches/commit` 整体提交，任何条目失败则整批不保存；输入和草稿保留。提交期间按钮禁用；网络重试复用提交编号，超时和结果未知时保留原请求、幂等头及草稿，跨刷新重试沿用原请求。

## 树与苹果独立成长

有效行动提供等权浇水反馈，并记录行动次数。树阶段只按该项目已手动收获的唯一目标数计算，不按行动数或待摘果实数计算。

`tree_stage = min(4, 1 + floor(harvest_count / K))`；默认 K=2，可在项目设置选 1 或 2，各项目独立。接口 `growth.stage` 沿用从 0 开始的索引，范围 0–3，对应产品阶段 1–4。

| 默认手动收获数 | 树阶段 |
| -------------- | ------ |
| 0–1            | 小树苗 |
| 2–3            | 幼树   |
| 4–5            | 茂盛树 |
| 6+             | 成熟树 |

苹果由目标进度决定：0% 小青果，(0,30]% 青果，(30,60]% 青黄果，(60,100)% 青红果，100% 红果成熟。数量和百分比进度上限截断；手动目标由用户确认后从 0 到 100%。

首页分别展示所有进行中项目的小树、树上目标苹果和独立果篮；项目详情显示四阶段图鉴、多个目标、行动倒序及果篮。过多项目通过自然滚动浏览。界面采用 2026-10-17 新参考图拆出的水彩手帐素材：天空花草欢迎页、草地树林、纸张对话、树与角色果篮收获场景。角色呼吸、星光和摘果动效尊重系统减少动态效果设置。

## 成果

目标满足完成条件后，系统在事务中生成唯一 Result 并通知前端。相关行动仅统计明确关联该 Goal 的有效 Action；灵感保留目标期间项目内的统计。天数从 Goal 创建自然日到达成自然日，包含起止日且最少一天。

成果保存标题、行动数、灵感数和天数快照。收获可选择继续方向、准备新目标或结束项目。果实成熟后仍留在树上，只有用户手动摘下才进入该项目的果篮，并参与该树升级。重复提交和并发收获只计算一次；结束项目和创建新目标分别调用独立接口，设置新目标入口位于项目详情。收获历史成果不会覆盖已经切换的新目标。

## 报告

7 天和 30 天包含今天，本月按上海自然月，全部包含历史记录。行动次数按实际发生日期筛选，活跃项目为周期内至少存在一条有效行动的不同项目，新成果按达成时间统计，包括已成熟待收获成果。

进度条显示当前目标；报告不展示周期百分比增长，避免与当前目标进度混淆。归档和结束项目的历史数据保留。默认总结为基于统计的固定模板；可额外点击生成 AI 回顾，数值仍以业务统计为准。

## 尚未纳入

手机号和第三方登录、跨设备账号恢复、日签分享、通知和主题切换。AI 草稿与语音转写已接入；新环境需确认语音模型额度后启用。备份当前支持 JSON 导出，尚无重新导入界面。升级会根据既有 harvestedAt 事实重新计算树阶段；不根据历史行动自动补收获，旧成果快照和已有数据不改写。
